# Voice Bot

[English](README.md) | [Русский](README.ru.md)

Telegram-бот для расшифровки голосовых сообщений и видеокружков через OpenAI.

- Полная расшифровка в сворачиваемой цитате и индикатор «печатает…» во время обработки.
- Пересказ записей от 15 секунд или каждой новой тройки коротких записей в пределах 10 минут.
- Контекст ответов из расшифровок, текста и подписей; отдельные счётчики для пользователей, чатов и тем.
- Автоматическая обработка или тихий режим с приватным ответом на `/text`.
- Постоянная очередь с восстановлением после перезапуска. Если речь не распознана, бот молчит.

## Запуск

Нужны Docker с Compose и ключ OpenAI API с доступом к выбранным моделям.

```sh
git clone https://github.com/eugeneb1ack/telegram-voice-bot.git
cd telegram-voice-bot
test -e .env || cp .env.example .env
```

Заполните `.env`:

| Переменная | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен бота из BotFather |
| `OPENAI_API_KEY` | Ключ OpenAI API |
| `OWNER_ID` | Telegram ID владельца бота |

Модели, лимиты и прокси настраиваются через [.env.example](.env.example).

```sh
docker compose up -d --build
docker compose logs -f voice-bot
```

В группе назначьте бота администратором, затем одобрите группу через `/admin` в личной переписке с ботом.

## Команды

| Команда | Действие |
| --- | --- |
| `/text` | Расшифровать запись, на которую дан ответ; в группе результат виден только запросившему |
| `/settings` | Выбрать автоматический или тихий режим; только для администраторов группы |
| `/start` | Показать справку |
| `/admin` | Одобрить или заблокировать группу; только для владельца |

Состояние хранится в Docker volume. Аудио и выбранный текстовый контекст отправляются в OpenAI для обработки.
