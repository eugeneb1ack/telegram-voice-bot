# Voice Bot

[English](README.md) | [Русский](README.ru.md)

Telegram-бот для расшифровки голосовых сообщений через OpenAI.

- Полная расшифровка в сворачиваемой цитате и индикатор «печатает…» во время обработки.
- Пересказ записей от 15 секунд или каждой тройки коротких записей со своим окном в 7 минут.
- Пересказ только текущих голосовых; отдельные счётчики для пользователей, чатов и тем.
- Текст, подписи, кружки и прошлые блоки исключены. Имена адресатов ответов сохраняются.
- Автоматическая обработка или тихий режим с приватным ответом на `/text`.
- Постоянная очередь с восстановлением после перезапуска. Если речь не распознана, бот молчит.
- Для записей только с приветствиями и междометиями — полная расшифровка без лишнего пересказа.

## Как пользоваться

Пришлите или перешлите боту голосовое. Полный текст раскрывается в ответе.
Краткая инструкция доступна по `/start` и `/help`. Для группы нажмите **Добавить в группу**,
назначьте бота администратором и дождитесь одобрения владельца бота: запрос уйдёт автоматически.
Команда `/help` в группе покажет её доступ и текущий режим обработки.

## Запуск

Нужны Docker с Compose и ключ OpenAI API с доступом к выбранным моделям.

```sh
git clone https://github.com/eugeneb1ack/telegram-voice-bot.git
cd telegram-voice-bot
test -e .env || cp .env.example .env
```

Заполните `.env`:

| Переменная | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен бота из BotFather |
| `OPENAI_API_KEY` | Ключ OpenAI API |
| `OWNER_ID` | Telegram ID владельца бота |

Модели, лимиты и прокси настраиваются через [.env.example](.env.example).

```sh
docker compose up -d --build
docker compose logs -f voice-bot
```

В группе назначьте бота администратором, затем одобрите группу через `/admin` в личной переписке с ботом.

## Команды

| Команда | Действие |
| --- | --- |
| `/text` | Расшифровать запись, на которую дан ответ; в группе результат виден только запросившему |
| `/settings` | Выбрать автоматический или тихий режим; только для администраторов группы |
| `/start` | Начать работу и добавить бота в группу |
| `/help` | Краткая инструкция; доступ и текущий режим группы |
| `/admin` | Одобрить или заблокировать группу; только для владельца |

Состояние хранится в Docker volume. Аудио и его расшифровки отправляются в OpenAI для обработки.

### Точность и стоимость сводок

Сводка сохраняет время событий, сомнения, просьбы и поправки из оригинала.
`SUMMARY_REASONING_EFFORT=low` включает лёгкое рассуждение Luna; `none` оставляет
минимальную стоимость. Настройки длины сводки и лимит голосового 600 секунд сохранены.
Рассуждение и итоговый текст вместе ограничены `SUMMARY_MAX_OUTPUT_TOKENS`. Если
ответ не завершён именно из-за этого лимита, выполняется одна повторная попытка
с `none`. Оборванные сводки не публикуются; полная расшифровка остаётся доступной.

### Надёжность доставки и проверка качества

Контейнер использует Python 3.14.10; CI также проверяет Python 3.12.16. Зависимости
закреплены в lock-файле. После явного отказа Telegram с `RetryAfter` готовый ответ
получает до трёх отложенных повторов в пределах `JOB_TIMEOUT_SECONDS`. Порядок внутри
чата и квитанции отправленных частей сохраняются. Ожидание освобождает worker,
повторных вызовов STT и summary нет. Неоднозначный сетевой исход остаётся на проверку,
чтобы избежать дубликатов. Блокировка бота или переход в тихий режим останавливают доставку.

Все сводки проходят строгую проверку структуры ответа. Принимается только завершённый
ответ assistant; отказы и оборванный текст не публикуются. Каждая распознанная запись
связана со своим автором и адресатом, в том числе в частично обработанной пачке.

Набор синтетических примеров проверяет время событий, отрицания, сомнения, поправки,
адресатов, инструкции внутри речи, разных авторов и бессодержательные записи:

```sh
uv run python scripts/evaluate_summaries.py
# Платная проверка через API; нужен OPENAI_API_KEY:
uv run python scripts/evaluate_summaries.py --execute
```

Без `--execute` запросов к API нет. Отчёт содержит результат и критерии ручной проверки:
корректный JSON сам по себе не доказывает точность пересказа.
